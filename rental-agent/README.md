# Rental Agent Pages (F3)

This module provides the front-desk interface for the car rental system.

## Features
- Agent dashboard
- Rental search and details
- Walk-in rental registration
- Vehicle return and late fee calculation
- Driver assignment
- Customer lookup
- Manager-only vehicle and driver changes
- Change history
